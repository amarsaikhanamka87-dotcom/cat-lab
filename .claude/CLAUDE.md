# Project instructions

## Code organization

1. **Readability and clear naming** - Variables, functions, and classes should have
   descriptive names
2. **Consistent patterns** - Follow the existing router/schema/model patterns in the

   codebase

3. **No hardcoded secrets** - Ensure API keys, tokens, and secrets use environment variables

# 1 logic to 1 file

- Follow separation of concerns and the Single Responsibility Principle.
- Organize related code by feature.
- Keep UI, business logic, validation, and database access separate.
- Keep modules focused and avoid unnecessary abstraction.
